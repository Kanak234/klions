# Security Policy

## Supported Versions

| Version | Supported          |
| ------- | ------------------ |
| 0.1.x   | :white_check_mark: |
| < 0.1   | :x:                |

## Reporting a Vulnerability

If you discover a security vulnerability in `klions`, please report it privately:

1. **Do NOT** open a public issue.
2. Submit a security advisory through GitHub or report directly to the repository maintainer.
3. Include detailed reproduction steps, compiler flags, and the relevant `.kl` source file or payload.

Reports will be acknowledged within 48 hours and security patches prioritised.
